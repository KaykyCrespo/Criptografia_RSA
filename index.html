Laboratório RSA

Demonstração acadêmica. Não use para proteger dados reais.

GUIA RÁPIDO

Como usar

  1. Escolha um método disponível e escreva uma mensagem de teste.
  2. Use Criptografar para gerar o texto cifrado e as chaves.
  3. O botão de seta transfere os valores para a área de descriptografia.
  4. Use Descriptografar para conferir a mensagem recuperada.

Disponibilidade: RSA, DES, Twofish-128 e SAFER K-64 cifram mensagens. TLS abre uma simulação didática de handshake.

Chaves: DES e SAFER K-64 usam 8 bytes; Twofish-128 usa 16. Os métodos simétricos também usam um IV e CBC com padding PKCS#7.

TLS: a simulação mostra etapas conceituais. Não cria certificados, não negocia segredos e não estabelece uma conexão TLS real.

Segurança: as cifras foram escritas para estudo e não devem proteger dados reais. DES é obsoleto, e as implementações não incluem autenticação.

Segurança: as implementações são educacionais e não devem proteger dados reais.
